# 06 Codex 完整版

依賴：01、02、03、04

## 目的

讓 Codex 使用者拿到與 Claude Code 對等的完整版：skill＋助手設定＋檢查腳本＋規則。

## 要做什麼

- 依 01 查到的 Codex 包裝格式，把 03 的三個 skill 放到 Codex 讀得到的位置。
- 三個助手設定轉寫成 Codex 的 TOML 格式。
- 提交指令：改成 Codex 可用的形式（依 01 的結論；若 Codex 沒有對應機制，寫明替代做法）。
- 檢查腳本：依 Codex 的事件機制接上，同樣是選用、沒有 Python 要明講「沒啟用」。若 Codex 的事件接不上，據實寫「Codex 版沒有這項」，並給手動替代做法。
- 規則：`AGENTS.md`（通用規則）放到 Codex 讀得到的位置或準備好貼上版本。
- 用本機 `codex-cli` 在隔離設定下做冒煙測試。

## 不做什麼

- 不為了 Codex 改動共用的 skill 內容（有差異放在 Codex 的包裝層）。
- 不寫說明書（09）。正式實裝是 12。

## 完成的樣子

- 在隔離設定下，Codex 裡看得到三個 skill 與三個助手（附畫面或指令輸出）。
- 一張「Claude Code 版有、Codex 版有沒有」的對照表，每個「沒有」都寫了原因與手動替代做法。
- 檢查腳本的兩種情況（啟用／沒啟用）各一份證據，或一句明確的「Codex 版不提供」。
