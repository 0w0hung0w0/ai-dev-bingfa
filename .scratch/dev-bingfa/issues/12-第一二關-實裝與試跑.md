# 12 第一、二關：乾淨環境實裝＋跑一個小任務

依賴：09、10

## 目的

證明「照說明書做真的裝得起來、真的能用」（規格第 8 節第 1、2 關）。

## 要做什麼

- 準備乾淨環境（不含使用者現有的 `~/.claude` 設定；做法在開工時定，例如另一個使用者帳號或隔離的設定資料夾，並說明它「乾淨」到什麼程度）。
- **第一關**：只看說明書一，一步步實裝 Claude Code 版與 Codex 版。每一步記錄：說明書寫的、實際看到的、是否一致。
- **第二關**：裝完後照說明書二跑示範小任務，Claude Code 與 Codex 各走完一次主線。
- 過程中發現說明書或包裹有錯：記下來、修正、把受影響的步驟重跑。
- 離線副本路線至少實裝一次。

## 不做什麼

- 不憑對包裹的了解「補做」說明書沒寫的步驟——沒寫就算說明書的缺陷。
- 不在使用者的日常環境驗證。
- 基本版不實測（規格已定）。

## 完成的樣子

- 一份驗證紀錄：兩個工具 × 兩關，每格是「通過／不通過」加畫面或輸出，以及使用者可以自己重做的步驟。
- 修正清單：發現了什麼、改了哪裡、重跑結果。
- 沒過的項目不發包，回到對應的卡修。
- `~/.claude` 前後沒有變動的證據。
