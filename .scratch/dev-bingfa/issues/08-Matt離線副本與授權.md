# 08 Matt Pocock 工具的離線副本與授權聲明

依賴：02

## 目的

同事的電腦若連不上 GitHub，還有備案可以裝 Matt 的工具；同時守住原作者的授權條件。

## 要做什麼

- 從官方來源取得 Matt 工具的一份副本放進包裹的離線資料夾，記錄取得日期與版本（提交編號）。
- 原封保留原作者的 MIT 授權聲明檔；另寫一份白話的「第三方內容聲明」，說明這部分是誰的、依什麼授權附上。
- 確認離線副本在 Claude Code 與 Codex 都有辦法從本地安裝（做法留給 09 寫成步驟，這裡只確認可行並記下指令）。

## 不做什麼

- 不修改 Matt 工具的內容。
- 不把離線副本當主線（主線是官方安裝）。
- 不從使用者的 `~/.claude` 外掛快取複製（來源要是官方，才能確定版本與授權檔完整）。

## 完成的樣子

- 離線資料夾裡看得到授權聲明檔，內容與官方一致。
- 一份紀錄：來源網址、版本、取得日期。
- 斷網情況下從本地安裝成功的證據（指令與輸出），Claude Code 與 Codex 各一份；做不到的據實寫明。
