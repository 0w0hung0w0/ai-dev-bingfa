# 09 說明書一：安裝

依賴：05、06、07、08

## 目的

讓不會寫程式的同事照著做就能裝好。

## 要做什麼

- 繁體中文。封面主標「AI 系統開發兵法」，副標「固定開發流程包」。
- 依工具分章：Claude Code、Codex（完整版）；Cursor、Antigravity（基本版，標「未實測」）。
- 每一步都是：「複製這行 → 貼到哪裡 → 看到什麼畫面代表成功」；加上「沒看到的話怎麼辦」。
- 涵蓋：事前準備（需要哪些軟體、怎麼確認有沒有）、Matt 工具官方安裝、連不上外網時改用離線副本、裝本包裹、手動貼上規則檔、個人偏好怎麼改、檢查腳本是選用（沒有 Python 會看到什麼）。
- 寫明「怎麼確認裝好了」的最後檢查，以及怎麼移除、怎麼退回舊版。
- 規格第 11 節仍未確認的事項，在對應章節明確標示。
- 問題回報給誰（維護人）。

## 不做什麼

- 不教流程怎麼用（那是 10）。
- 不寫沒有實際跑過的步驟；完整版的每一步都要是 05、06 實際成功過的指令。

## 完成的樣子

- 使用者自己讀一遍，沒有看不懂的詞；有的話列出來改掉。
- 每一步都有「成功長什麼樣」。
- 正式的照做驗證在 12（第一關）與 14（同事實裝）。
