# 10 說明書二：第一次使用

依賴：05、06（寫作時參考 09 的用語）

## 目的

帶同事用一個小任務走完整條主線，做完就知道日常怎麼用。

## 要做什麼

- 挑一個不會寫程式的人也能懂、十幾分鐘到半小時能走完的示範小任務。
- 照主線六步寫：追問需求 → 寫規格 → 切任務卡 → 先測試再實作 → 獨立審查 → 交付與檢討。每一步寫：打什麼、AI 會回什麼樣的東西、你要做什麼決定、怎樣算這一步完成。
- 補上三個補充 skill 什麼時候用（接手既有專案、改到共用的東西、跨元件交付）。
- Claude Code 與 Codex 指令不同的地方並列；基本版使用者在「獨立審查」「自動攔錯」兩處指向手動替代做法。
- 任務卡預設放本地檔案；註明已在用 GitHub Issues 的團隊可以改選。

## 不做什麼

- 不重複安裝步驟。
- 示範任務不依賴公司內部系統或任何帳號。

## 完成的樣子

- 一份照著做就能走完的教學；示範任務的每一步都是實際跑過的（證據在 12 第二關補齊）。
- 使用者自己讀一遍，沒有看不懂的詞。
