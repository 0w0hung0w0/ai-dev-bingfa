## 3. 本機安裝測試

誠實說明：我無法真的拔網路線。能證明的是這幾道安裝指令的來源參數都是本機路徑，沒有 `owner/repo` 或網址；兩個工具的設定檔也都記錄 source 為本機路徑（Codex 的 `source_type = "local"`，Claude 的 `settings.json` 為 directory 來源）。但我沒有用封鎖網路的方式再跑一次，所以「斷網下成功」未被直接證明。

### 發現：直接把 `mattpocock-skills/` 當 marketplace，Codex 失敗

Matt 的 marketplace 檔寫 `"source": "./"`（外掛就是 marketplace 根目錄本身）。

Claude Code：成功。

Codex 0.140.0：失敗。
```
> codex plugin marketplace add <...>\離線副本\mattpocock-skills
Added marketplace `mattpocock` from ...
> codex plugin add mattpocock-skills@mattpocock
Error: plugin `mattpocock-skills` was not found in marketplace `mattpocock`
> codex plugin list
No marketplace plugins found.
```
我另在暫存資料夾（已刪除）驗證：把外掛放到子資料夾、由外層 marketplace 用 `"source": "./mattpocock-skills"` 指過去，就安裝成功。推論是 Codex 0.140.0 不接受 `"./"` 這種指向 marketplace 根目錄的來源（這是由兩次對照推出的，未查 Codex 原始碼）。

新增 `dev-bingfa/離線副本/.claude-plugin/marketplace.json`（本套件作者所寫，內容只有一筆，`source` 為 `./mattpocock-skills`）。之後兩個工具都指向 `離線副本/` 這一層。
