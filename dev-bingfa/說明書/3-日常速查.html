卡住時怎麼辦

狀況怎麼做
打 /（Claude）或 $（Codex）看不到這些指令完全關閉 App（右下角系統匣的圖示也要結束）再重開，開新對話再試。Claude 版確認包裹資料夾沒有被搬動或改名。還是沒有 → 說明書一第 9 章，再回報。
AI 自己開始做「只有你能啟動」的步驟說：「這個要等我叫。」需要時你自己打那個指令。
追問需求問個沒完說：「請把範圍縮到最小，剩下的都用你建議的答案。」
還在追問或寫規格，AI 就開始寫程式說：「先不要寫程式，我們還在問需求。」
AI 說要先跑 setup-matt-pocock-skills這個專案還沒做「準備」。照第 2 頁第一列打一次，任務卡選「本地檔案」。
審查說「沒有改動可以比」，或不知道從哪個存檔點審通常是做完忘了存版本：先打 commit 存版本，再審。每張卡開始前問 AI「目前最新的存檔點編號是什麼？」記下來，審查就說「從存檔點【編號】之後」。
沒有 Git存版本跳過，並記得這次沒有存檔點。獨立審查改成：開全新對話，請它對照規格和任務卡審查檔案、只審不改（完整句子在說明書二第 6 章）未實測 二#7。
AI 說「做好了」，但沒有證據、或沒有三個標題說：「請補上：漏了什麼、放棄了什麼、猜了什麼，各在哪裡看得到，並用 Blocked on me／Changed／Found 三個標題收尾。」你自己打開成果用一次才算驗收。
AI 說它沒辦法自己執行測試，或要安裝 Node、Python 等軟體安裝的確認按拒絕，說：「不要安裝任何軟體，請用自我測試頁。」請它說清楚是怎麼確認的，你自己按兩下打開自我測試頁看。
存版本時 Git 說不知道你是誰說：「請只為這個專案資料夾設定 Git 的名字和 email：名字用「【代號】」，email 用 practice@example.com。只用 git config，不要加 --global。」設不起來就當成沒有 Git（上一列）。
對話太長、AI 開始忘記前面說過的事打 handoff 寫交接文件，開新對話接著做。以後一個對話只做一張任務卡。

改到 Python 檔、但「存檔自動檢查」沒啟用時（Codex，或沒有 Python 的 Claude），交付前貼這句：

交付前請檢查：這次改過的 Python 檔裡，有沒有 `except Exception:` 或 `except:` 後面只有 `pass` 的地方？每一處請說明上游怎麼知道失敗、我在哪裡看得到。

按「複製」沒反應：用滑鼠把框裡的字整段選起來，按 Ctrl+C。

什麼時候可以跳過步驟

  • 只改一行的小修正（例如改一個錯字、改一個數字）：整個流程都可以跳過。
  • 只動一個頁面、沒碰到共用東西的小改動（改文字、改樣式、只在這一頁用的邏輯）：可以跳過 blast-radius，但獨立審查（code-review）不能跳。
  • 其他所有改動：照流程走，獨立審查一定要做。
  • 一個對話只做一張任務卡；太大一個對話做不完的工作，先切成任務卡。
