# 更新紀錄

每一版改了什麼、要不要重裝。舊版的壓縮檔保留不刪，新版有問題可以退回。

## 1.0（2026-11-25）

壓縮檔：`dev-bingfa-1.0.zip`。這是第一版。

### 這一版有什麼

- **Claude 桌面 App（Code 分頁）：完整版。** 照 `安裝指示-ClaudeCode.md` 裝四樣東西：
  1. Matt Pocock 的工具（連得上 GitHub 就用官方方式裝，連不上就用包裹裡的離線副本）。
  2. 本包裹的主外掛：四個固定流程（專案探勘、影響範圍檢查、接縫對帳、提交）、三個助手（讀碼、實作、網路搜尋）和網路搜尋策略。
  3. 通用規則：附加在你的規則檔尾端，裝之前會先備份。
  4. 存檔時自動檢查（選用）：電腦有 Python 才裝；沒有 Python 就不裝，安裝結果表會寫「沒啟用」。
- **ChatGPT 桌面 App 裡的 Codex：用複製檔案的方式安裝。** 照 `安裝指示-Codex.md` 把同樣的固定流程、三個助手（Codex 格式）、搜尋策略和通用規則複製過去。**不裝存檔自動檢查**（在 Codex 上沒有測試成功）。
- **基本版（Cursor、Antigravity 等）：未實測。** `基本版/` 裡的檔案直接複製就能用，但沒有在這些工具裡實際試過。
- 三份說明書（`說明書/` 裡的 `1-安裝.html`、`2-第一次使用.html`、`3-日常速查.html`）、移除指示、AI 不能執行指令時的備案。

### 要不要重裝

- 第一次安裝，不適用。
- 之後每一版會在這裡寫明三件事：Claude 版要不要重裝、Codex 版要不要重裝、為什麼。例如「不用重裝（只改了說明書）」、「Claude 版要重裝：解壓到新資料夾再說一次安裝句」、「Codex 版要先用舊版包裹移除，再用新版包裹安裝」。做法在說明書 1 第 8 章。

### 已知限制、還沒確認的事

- 裝好 Claude 版之後，包裹資料夾**不能搬動、改名或刪除**，搬走 Claude 會馬上讀不到外掛。
- Codex 版沒有存檔自動檢查；Codex 裡的固定流程和助手清單會不會照預期出現，還沒在真的 App 裡確認。
- 基本版整章未實測。
- 沒有在真正斷網的電腦上試過；升級、退回舊版的整條流程也還沒從頭做過。
- App 畫面（按鈕名稱、確認視窗出現幾次）沒有逐一核對。
- 完整清單（共 13 項，每項有編號）在說明書 1 **第 10 章「目前還沒確認的事」**。回報問題時說編號就好。
