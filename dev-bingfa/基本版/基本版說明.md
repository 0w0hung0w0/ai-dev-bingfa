# 基本版說明（Cursor、Antigravity 等工具）

這一頁寫給不會寫程式的人。它說明基本版裝了什麼、比完整版少了什麼，以及少掉的部分要怎麼用手動方式補上。
詳細的安裝步驟請看說明書的「安裝」那一份，這裡不重複。

> **先講清楚：基本版整包都沒有實際測試過（未實測）。**
> 維護人手上沒有 Cursor 和 Antigravity 可以試，下面關於這兩個工具會怎麼表現的說法，都是根據官方文件或網路摘要推測的。
> 照做時如果跟這裡寫的不一樣，請回報給維護人。

---

## 1. 基本版裡有什麼

把這個資料夾裡的東西複製到你自己的專案資料夾最上層，就會變成：

```
你的專案資料夾/
├── AGENTS.md                  ← 通用規則（AI 該怎麼做事）
└── .agents/
    └── skills/
        ├── brownfield-recon/SKILL.md   ← 既有專案探勘
        ├── blast-radius/SKILL.md       ← 影響範圍檢查
        ├── seam-audit/SKILL.md         ← 接縫對帳
        └── commit/
            ├── SKILL.md                ← 提交（存一個版本到 git）
            └── agents/openai.yaml      ← 給 Codex 看的設定（不讓 AI 自己提交），其他工具用不到，留著無妨
```

- 名稱前面有一個點的資料夾（`.agents`）在 Windows 檔案總管裡可能看不到，那是正常的「隱藏資料夾」。
- 如果你的專案資料夾裡**已經有** `AGENTS.md`，不要直接蓋掉。把基本版 `AGENTS.md` 的內容貼到原本檔案的最後面。
- 你自己改好的「個人偏好」（見 `規則/個人偏好範例.md`）也貼在 `AGENTS.md` 最後面。
- 這份 `基本版說明.md` 本身不用複製進專案，複製了也沒有影響。
- Matt Pocock 的工具（`grill-me`、`to-spec`、`tdd`、`code-review` 等）不在這個資料夾裡，請照說明書「安裝」那一份的步驟另外裝。

### 怎麼叫出 skill

每個工具叫出 skill 的方式不一樣，而且**都未實測**，所以這裡不寫指令格式，免得寫錯。
最保險的做法是直接用一般的話跟 AI 說，例如：

```
請使用 brownfield-recon 這個 skill，幫我探勘這個專案。
```

如果 AI 回答它找不到這個 skill，代表 skill 沒有被讀到，請回報維護人。
只有 `commit` 例外：它被設定成「AI 不能自己啟動、只能由你叫」，所以 AI 有可能回答「我不能自己啟動 commit」。這不是沒讀到，請照 3-3 最後的做法改用別的叫法。

## 2. 基本版少了什麼

完整版（Claude Code、Codex）有三樣基本版沒有的東西：

| 完整版有的 | 用處 | 基本版怎麼補 |
|---|---|---|
| 助手（另一個 AI 分頭做事） | 讀大量程式碼、實作、獨立審查都交給另一個 AI，主對話只負責規劃和把關 | 主對話自己讀、自己改；獨立審查改成**你手動開新對話**（見 3-1） |
| 存檔時自動檢查 | AI 每寫完一個檔案，電腦自動掃一次常見錯誤 | **交付前請 AI 照清單自己走一遍**（見 3-2） |
| 提交交給助手 | 存版本這件事由助手做 | **由你自己叫出 `commit` 這個 skill**（見 3-3） |

## 3. 手動補法

### 3-1. 獨立審查：開一個全新的對話來審

**為什麼要「全新」的對話？**
寫程式的那個對話，腦子裡裝滿了「我本來想怎麼做」。叫它審自己的東西，它很容易看到自己想看的，而不是實際寫出來的。
全新的對話什麼前情都不知道，只能看實際的改動，比較像一個外人來檢查。所以**不要在同一個對話裡請它審**。

**怎麼做：**

1. AI 做完一小塊改動後，先記下「這次改動是從哪裡開始的」。最簡單的說法是：請原本的對話告訴你「改動前最後一個 commit 的編號」，或直接說「還沒 commit 的改動」。
2. 在你的工具裡開一個**新的對話**（新視窗、新分頁都可以，重點是看不到之前的聊天內容）。
3. 貼上下面這段，把【】裡的字換掉：

```
請使用 code-review 這個 skill，審查這個專案【從 commit xxxxxxx 之後的改動／目前還沒 commit 的改動】。
這次改動要做的事是：【用一兩句話說明，或貼上任務卡檔案的路徑】。
請只審查、不要修改任何檔案。
審查結果請按嚴重程度排列，每一項附上檔案位置和理由。
```

4. 把審查結果拿回原本的對話，請它逐項處理或說明為什麼不用改。

注意（未實測）：
- `code-review` 這個 skill 原本的設計會再分派給助手平行審查。基本版的工具不一定支援助手，它可能改成自己一項一項審，也可能做不完整。如果它說做不到，請照它能做的範圍審，並回報維護人。
- 這個 skill 要在 Matt Pocock 的工具裝好之後才有。

### 3-2. 交付前的檢查清單（取代「存檔時自動檢查」）

完整版的自動檢查只抓一種錯：**Python 程式裡「出錯了就當作沒事」的寫法**。
例如程式寫了「如果出錯，什麼都不做」（`except:` 或 `except Exception:` 底下只有一行 `pass`）。
這種寫法的問題是：東西壞了，卻沒有任何人知道，畫面上也看不到。

基本版沒有這個自動檢查，所以在 AI 說「做完了」的時候，請貼上下面這段，叫它自己照清單走一遍：

```
交付前請照這張清單逐項檢查，每一項回答「有／沒有」並附上檔案位置：

1. 這次改到的 Python 檔（.py）裡，有沒有「except:」、「except Exception:」或「except BaseException:」底下只寫 pass、什麼都不做的地方？
   （測試檔、只是在嘗試載入選用套件的地方可以除外，但請說明。）
   如果有，每一處都要回答：
   - 這裡出錯被吞掉之後，上游怎麼知道這一步失敗了？
   - 使用者在哪裡看得到？（只寫進 log 不算）
   兩題都答不出來，就請改成至少留下痕跡，或改成只接住具體的錯誤種類；確定應該吞掉的，要在程式碼註解寫明理由。
2. 你漏掉了什麼、放棄了什麼、哪些是猜的？使用者分別在哪裡看得到？
3. 有沒有「做不到卻沒說」的地方？每一種失敗的情況，使用者都要看得到，只寫 log 不算。
4. 最後用三個標題收尾：「卡在我這裡的事」「改了什麼」「發現了什麼」。
```

第 2 到 4 項來自通用規則 `AGENTS.md` 第 7 節「沉默就是缺陷」。
這份清單是靠 AI 自己檢查，**不像自動檢查那樣每次都一定會跑**，請養成每次交付都貼一次的習慣。

### 3-3. 沒有助手：主對話自己做、你自己叫 commit

- 通用規則裡寫的「把讀程式碼和實作交給助手」，在沒有助手的工具上，就由**主對話自己讀、自己改**。這是正常的，不用特別處理。
- 但因為讀和寫都在同一個對話裡，對話會很快變長。一個對話只做一張任務卡，做完就開新對話，效果會比較好。
- **存版本（commit）一律由你自己叫出 `commit` 這個 skill**，不要讓 AI 自己決定什麼時候存。可以這樣說：

```
請使用 commit 這個 skill，幫我把這次的改動提交。
```

如果 AI 說它不能自己啟動 `commit`（未實測，有些工具會這樣擋）：
1. 改用工具的斜線指令或 skill 選單叫它，例如在對話框輸入 `/commit`（未實測，每個工具的叫法可能不同）。
2. 還是不行，就貼這句：

```
請照 .agents/skills/commit/SKILL.md 的步驟，幫我把這次的改動提交。
```

## 4. Cursor 要注意的事

**Cursor 會不會每次對話都自動讀 `AGENTS.md`：官方文件沒寫清楚，未實測。**
官方只說可以把 `AGENTS.md` 放在專案最上層當作規則用，沒有明說每一次對話都會讀進去。

**一分鐘自我測試：**

1. 把基本版複製進專案後，在 Cursor 開一個**新的對話**。
2. 問它：

```
你看到哪些專案規則？請列出規則檔的檔名，並說出第 7 節的標題。
```

3. 看回答：
   - 它說出 `AGENTS.md`，而且第 7 節標題是「Silence Is a Defect」（沉默就是缺陷）→ 有讀到，可以正常用。
   - 它說沒看到規則、或答不出第 7 節 → 沒讀到，照下面做。

**沒讀到的時候：**
每次開新對話，第一句先說：

```
請先讀專案最上層的 AGENTS.md，之後都照裡面的規則做事。
```

再回報維護人，說明你用的 Cursor 版本。

（Cursor 讀 `.agents/skills/` 這個資料夾，是根據官方文件的摘要，也未實測。）

## 5. Antigravity 要注意的事

- **只教裝在專案資料夾**（也就是照第 1 節，把東西放在你的專案資料夾裡）。
  「整台電腦都能用」的安裝位置，網路上有好幾種互相矛盾的說法，所以不教。
- Antigravity 會讀專案資料夾裡的 `.agents/skills/` 和 `AGENTS.md`：這是根據 Google 的教學頁和搜尋摘要推測的，**官方說明網站當時連不上，一頁都沒讀到，未實測**。
- 建議也做一次第 4 節的「一分鐘自我測試」，確認它有讀到 `AGENTS.md`。沒讀到的話，處理方式和 Cursor 一樣。
