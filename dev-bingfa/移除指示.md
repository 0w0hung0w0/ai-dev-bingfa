# 移除指示（Claude 桌面 App／ChatGPT 桌面 App 裡的 Codex）

> **給同事看的三行**
> 1. 在要移除的那個 App 開新對話（資料夾選這個包裹資料夾），說：「請讀 `移除指示.md`，幫我移除 Claude Code 版」或「……移除 Codex 版」。想連 Matt Pocock 的工具一起移除，要另外說「Matt 的工具也一起移除」。
> 2. AI 會跳出好幾次「要不要允許」的確認：它要移除外掛、把複製進去的檔案移到一個備份資料夾、從規則檔拿掉本包裹那一段（會先備份）。如果它要你登入、輸入密碼、或改權限設定，按拒絕。
> 3. 做完要把 App **完全關閉**再重開。

---

以下是給 AI 的指示。

## 規則（全程遵守）

- 只做使用者說的那個工具（Claude Code 或 Codex）。照順序、指令照抄，唯一要換的是 `<ROOT>`（這份檔案所在的資料夾的完整路徑，保留兩邊的單引號）。
- 用 PowerShell 執行。每個指令區塊是一次完整執行的單位。
- 只移除本包裹裝的東西（下面寫明的清單）。**Matt Pocock 的工具預設保留**，使用者明確說要一起移除才做 Matt 那一步。
- 不刪除使用者的檔案：Codex 版複製進去的檔案是「移到備份資料夾」，不是刪掉。**只移走和這個包裹裡的副本一模一樣的檔案**；內容不一樣的（可能被使用者改過、或是用不同版本的包裹裝的）一律不動，標 `KEEP` 回報給使用者。所以請用**安裝時那個版本**的包裹來移除；拿別的版本來移除，會全部變成 `KEEP`、什麼都不動。
- 規則檔先備份，只拿掉 `<!-- dev-bingfa:start … -->` 到 `<!-- dev-bingfa:end -->` 那一段（安裝時為了讓標記換行而補的那個換行也一起拿掉）。結束標記下面的 `## Personal Preferences` 是使用者自己的個人偏好，**留著不動**。只有一種情況會刪掉規則檔：這個檔是安裝時新建的（標記裡有 `new`），而且拿掉區塊後完全是空的。
- 失敗、出現 `STOP`、或遇到沒寫到的情況：停下來，用白話繁體中文回報，不要自己想辦法。
- 不登入、不讀或印出任何密碼與憑證、不改權限或安全設定、不替使用者按允許。

## A. 移除 Claude Code 版

### A1 移除外掛

```powershell
$c = (Get-Command claude -CommandType Application -ErrorAction SilentlyContinue | Select-Object -First 1).Source
if (-not $c) { $c = (Get-ChildItem -LiteralPath "$env:APPDATA\Claude\claude-code" -Directory -ErrorAction SilentlyContinue | Get-ChildItem -Directory | ForEach-Object { Get-Item -LiteralPath (Join-Path $_.FullName 'claude.exe') -ErrorAction SilentlyContinue } | Sort-Object { try { [version]$_.Directory.Parent.Name } catch { [version]'0.0' } } -Descending | Select-Object -First 1).FullName }
if (-not $c) { 'STOP 找不到 Claude Code 程式'; return }
$ids = @((& $c plugin list --json | Out-String | ConvertFrom-Json) | ForEach-Object { $_.id })
foreach ($p in 'dev-bingfa-check@dev-bingfa', 'dev-bingfa@dev-bingfa') {
  if ($ids -contains $p) { & $c plugin uninstall $p; '結束碼：' + $LASTEXITCODE } else { '本來就沒裝：' + $p }
}
& $c plugin marketplace remove dev-bingfa
'結束碼：' + $LASTEXITCODE
& $c plugin list
```

**成功的樣子**：每個裝過的外掛都有 `Successfully uninstalled`（或 `本來就沒裝`），`marketplace remove` 那行成功（如果顯示找不到 `dev-bingfa` marketplace，代表本來就沒有，也算成功）；最後的清單裡沒有 `dev-bingfa`。

### A2 Matt Pocock 的工具（只有使用者明確要求才做）

```powershell
$c = (Get-Command claude -CommandType Application -ErrorAction SilentlyContinue | Select-Object -First 1).Source
if (-not $c) { $c = (Get-ChildItem -LiteralPath "$env:APPDATA\Claude\claude-code" -Directory -ErrorAction SilentlyContinue | Get-ChildItem -Directory | ForEach-Object { Get-Item -LiteralPath (Join-Path $_.FullName 'claude.exe') -ErrorAction SilentlyContinue } | Sort-Object { try { [version]$_.Directory.Parent.Name } catch { [version]'0.0' } } -Descending | Select-Object -First 1).FullName }

foreach ($p in @($ids | Where-Object { $_ -like 'mattpocock-skills@*' })) { & $c plugin uninstall $p; '結束碼：' + $LASTEXITCODE }
if ((& $c plugin marketplace list | Out-String) -match 'mattpocock-offline') { & $c plugin marketplace remove mattpocock-offline; '結束碼：' + $LASTEXITCODE }
& $c plugin list
```

**成功的樣子**：清單裡沒有 `mattpocock-skills`。（官方的 `claude-plugins-official` 外掛目錄不移除，因為使用者可能還有別的外掛從那裡裝。）

### A3 從 `CLAUDE.md` 拿掉本包裹的規則

```powershell
$dir = if ($env:CLAUDE_CONFIG_DIR) { $env:CLAUDE_CONFIG_DIR } else { Join-Path $env:USERPROFILE '.claude' }
$target = Join-Path $dir 'CLAUDE.md'
if (-not (Test-Path -LiteralPath $target)) { 'OK 沒有規則檔，不用處理：' + $target; return }
$enc = New-Object System.Text.UTF8Encoding($false, $true)
$bytes = [IO.File]::ReadAllBytes($target)
$bom = ($bytes.Length -ge 3 -and $bytes[0] -eq 0xEF -and $bytes[1] -eq 0xBB -and $bytes[2] -eq 0xBF)
$off = 0; if ($bom) { $off = 3 }
try { $old = $enc.GetString($bytes, $off, $bytes.Length - $off) } catch { 'STOP 規則檔不是 UTF-8 編碼，沒有改它：' + $target; return }
$mS = '<!-- dev-bingfa:start '; $mE = '<!-- dev-bingfa:end -->'
$nS = [regex]::Matches($old, [regex]::Escape($mS)).Count; $nE = [regex]::Matches($old, [regex]::Escape($mE)).Count
if ($nS -eq 0 -and $nE -eq 0) { 'OK 規則檔裡沒有 dev-bingfa 區塊，不用處理：' + $target; return }
if ($nS -ne 1 -or $nE -ne 1) { 'STOP 標記不成對或不只一組（開始 ' + $nS + ' 個、結束 ' + $nE + ' 個），沒有改它：' + $target; return }
$iS = $old.IndexOf($mS); $iE = $old.IndexOf($mE)
if ($iE -lt $iS) { 'STOP 標記順序顛倒，沒有改它：' + $target; return }
$flag = ''; if ($old.Substring($iS, $iE - $iS) -match '^<!-- dev-bingfa:start \S+( nl| new)? -->') { $flag = [string]$Matches[1] }
$iE += $mE.Length
if ($old.Substring($iE).StartsWith("`r`n")) { $iE += 2 } elseif ($old.Substring($iE).StartsWith("`n")) { $iE += 1 }
$cutAt = $iS
if ($flag -eq ' nl') { if ($old.Substring(0, $iS).EndsWith("`r`n")) { $cutAt -= 2 } elseif ($old.Substring(0, $iS).EndsWith("`n")) { $cutAt -= 1 } }
$new = $old.Substring(0, $cutAt) + $old.Substring($iE)
$stamp = Get-Date -Format 'yyyyMMdd-HHmmss-fff'; $backup = $target + '.bak-dev-bingfa-' + $stamp; $i = 1
while (Test-Path -LiteralPath $backup) { $backup = $target + '.bak-dev-bingfa-' + $stamp + '-' + $i; $i++ }
Copy-Item -LiteralPath $target -Destination $backup
if ($flag -eq ' new' -and $new.Length -eq 0) { Remove-Item -LiteralPath $target; 'OK 已拿掉 dev-bingfa 區塊；這個檔是安裝時新建的、現在是空的，已刪除：' + $target; '備份：' + $backup; return }
[byte[]]$out = $enc.GetBytes($new)
if ($bom) { [byte[]]$out = [byte[]](0xEF, 0xBB, 0xBF) + $out }
[IO.File]::WriteAllBytes($target, $out)
$chk = $enc.GetString([IO.File]::ReadAllBytes($target))
if ($chk.Contains($mS) -or $chk.Contains($mE)) { 'STOP 移除後還看得到標記，請用備份還原：' + $backup } else { 'OK 已拿掉 dev-bingfa 區塊：' + $target; '備份：' + $backup; '標記外面的內容（包括 Personal Preferences 個人偏好）都留著，沒有動；剩下 ' + (Get-Item -LiteralPath $target).Length + ' 位元組' }
```

**成功的樣子**：`OK 已拿掉 dev-bingfa 區塊：…`（或 `不用處理`）和 `備份：…`。回報時告訴使用者：「規則檔裡你自己的內容，包括 `## Personal Preferences` 個人偏好，都留著；不要的話可以自己刪掉那一段。」

### A4 確認包裹資料夾還有沒有人在讀（一定要做）

```powershell
$root = '<ROOT>'
$c = (Get-Command claude -CommandType Application -ErrorAction SilentlyContinue | Select-Object -First 1).Source
if (-not $c) { $c = (Get-ChildItem -LiteralPath "$env:APPDATA\Claude\claude-code" -Directory -ErrorAction SilentlyContinue | Get-ChildItem -Directory | ForEach-Object { Get-Item -LiteralPath (Join-Path $_.FullName 'claude.exe') -ErrorAction SilentlyContinue } | Sort-Object { try { [version]$_.Directory.Parent.Name } catch { [version]'0.0' } } -Descending | Select-Object -First 1).FullName }
$off = @(@((& $c plugin marketplace list --json | Out-String | ConvertFrom-Json) | ForEach-Object { $_ }) | Where-Object { $_.name -eq 'mattpocock-offline' }) | Select-Object -First 1
if (-not $off) { 'FOLDER-FREE 沒有東西在讀離線副本' }
elseif (($off.path.TrimEnd('\') + '\').StartsWith($root.TrimEnd('\') + '\', [StringComparison]::OrdinalIgnoreCase)) { 'FOLDER-IN-USE Matt 的工具還在讀這個包裹的離線副本：' + $off.path }
else { 'FOLDER-OTHER Matt 的工具讀的是另一個資料夾的離線副本：' + $off.path }
```

**成功的樣子**：最後一行是 `FOLDER-FREE …`、`FOLDER-IN-USE …` 或 `FOLDER-OTHER …` 其中一種。記下來，最後回報要用。

## B. 移除 Codex 版（複製檔案路線）

### B1 把本包裹複製進去的檔案移到備份資料夾

只處理這份清單：`%USERPROFILE%\.agents\skills\` 底下的 `blast-radius`、`brownfield-recon`、`commit`、`seam-audit`；Codex 設定資料夾 `agents\` 底下的 `bingfa-explorer.toml`、`bingfa-implementer.toml`、`bingfa-web-search-agent.toml`、`bingfa-web-search-modules`。內容和包裹一模一樣的才移走。

```powershell
$root = '<ROOT>'
$cx = if ($env:CODEX_HOME) { $env:CODEX_HOME } else { Join-Path $env:USERPROFILE '.codex' }
$sk = Join-Path $env:USERPROFILE '.agents\skills'
$bk = Join-Path $env:USERPROFILE ('dev-bingfa-removed-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
$pairs = @()
foreach ($n in 'blast-radius', 'brownfield-recon', 'commit', 'seam-audit') { $pairs += , @((Join-Path $root "外掛\dev-bingfa\skills\$n"), (Join-Path $sk $n)) }
foreach ($n in 'bingfa-explorer.toml', 'bingfa-implementer.toml', 'bingfa-web-search-agent.toml') { $pairs += , @((Join-Path $root "codex\agents\$n"), (Join-Path $cx "agents\$n")) }
$pairs += , @((Join-Path $root '外掛\dev-bingfa\web-search-modules'), (Join-Path $cx 'agents\bingfa-web-search-modules'))
$tree = { param($p) if (Test-Path -LiteralPath $p -PathType Leaf) { (Get-FileHash -LiteralPath $p -Algorithm SHA256).Hash } else { Get-ChildItem -LiteralPath $p -Recurse -File -Force | Sort-Object FullName | ForEach-Object { $_.FullName.Substring($p.Length) + '=' + (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash } } }
foreach ($pr in $pairs) {
  $src = $pr[0]; $dst = $pr[1]
  if (-not (Test-Path -LiteralPath $dst)) { '本來就沒有：' + $dst; continue }
  if (((& $tree $src) -join '|') -ne ((& $tree $dst) -join '|')) { 'KEEP 內容和包裹不一樣，沒有動（請使用者決定）：' + $dst; continue }
  $to = Join-Path $bk ((Split-Path (Split-Path $dst -Parent) -Leaf) + '\' + (Split-Path $dst -Leaf))
  New-Item -ItemType Directory -Force -Path (Split-Path $to -Parent) | Out-Null
  Move-Item -LiteralPath $dst -Destination $to
  '已移到備份：' + $dst
}
if (Test-Path -LiteralPath $bk) { 'OK 備份資料夾：' + $bk } else { 'OK 沒有需要移走的檔案' }
```

**成功的樣子**：每一項是「已移到備份」或「本來就沒有」，最後一行 `OK …`。有 `KEEP` 的項目要在回報裡列出來。

### B2 Matt Pocock 的工具（只有使用者明確要求才做）

只移走和包裹離線副本一模一樣的 Matt skill 資料夾（清單取自離線副本的 `plugin.json`）。

```powershell
$root = '<ROOT>'
$sk = Join-Path $env:USERPROFILE '.agents\skills'
$bk = Join-Path $env:USERPROFILE ('dev-bingfa-removed-matt-' + (Get-Date -Format 'yyyyMMdd-HHmmss-fff'))
$base = Join-Path $root '離線副本\mattpocock-skills'
$pj = Get-Content -LiteralPath (Join-Path $base '.claude-plugin\plugin.json') -Raw -Encoding UTF8 | ConvertFrom-Json
$tree = { param($p) Get-ChildItem -LiteralPath $p -Recurse -File -Force | Sort-Object FullName | ForEach-Object { $_.FullName.Substring($p.Length) + '=' + (Get-FileHash -LiteralPath $_.FullName -Algorithm SHA256).Hash } }
foreach ($rel in $pj.skills) {
  $src = Join-Path $base (($rel -replace '^\./', '') -replace '/', '\'); $n = Split-Path $src -Leaf; $dst = Join-Path $sk $n
  if (-not (Test-Path -LiteralPath $dst)) { '本來就沒有：' + $n; continue }
  if (((& $tree $src) -join '|') -ne ((& $tree $dst) -join '|')) { 'KEEP 內容和離線副本不一樣，沒有動：' + $dst; continue }
  New-Item -ItemType Directory -Force -Path $bk | Out-Null
  Move-Item -LiteralPath $dst -Destination (Join-Path $bk $n)
  '已移到備份：' + $n
}
if (Test-Path -LiteralPath $bk) { 'OK 備份資料夾：' + $bk } else { 'OK 沒有需要移走的檔案' }
```

如果 Matt 的工具是用 Codex 外掛裝的（不是本包裹複製的），這一步不會動它；請告訴使用者那要用 `codex` 指令或 App 的 Plugins 分頁移除。

## 最後回報

給使用者一張表：

| 項目 | 結果（已移除／本來就沒有／保留） | 說明 |
|---|---|---|

- 寫出規則檔的備份位置，並說個人偏好那段留著沒動；Codex 版寫出備份資料夾位置，並說「確定不需要之後，你可以自己刪掉這個備份資料夾」。
- 列出所有 `KEEP`（沒動）的項目和原因。
- Matt 的工具有沒有動、為什麼。
- 提醒：「請把 App 完全關閉再重開。」
- 包裹資料夾能不能刪，看 A4 的結果（只移除 Codex 版時不用 A4，直接說「Codex 版不讀包裹資料夾；如果你的 Claude Code 也裝過本包裹，先別刪」）：
  - `FOLDER-FREE` →「Claude Code 已經不讀這個包裹資料夾了，可以刪掉或搬走。」
  - `FOLDER-IN-USE` →「包裹資料夾**還不能刪**：Matt 的工具還在讀它的離線副本（寫出路徑）。要刪，就先請我連 Matt 的工具一起移除；或之後用新版包裹重裝一次，讓 Matt 改讀新資料夾。」
  - `FOLDER-OTHER` →「這個包裹資料夾可以刪；但 Matt 的工具讀的是另一個資料夾（寫出路徑），**那個資料夾**不能刪。」
