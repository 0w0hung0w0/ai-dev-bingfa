# 貼指令備案（AI 沒辦法幫你執行指令時才用）

平常請用 `安裝指示-ClaudeCode.md`／`安裝指示-Codex.md`，讓 AI 幫你裝。只有 AI 說它不能執行指令、或一直失敗時，才照這一頁自己做。步驟和 AI 做的一樣。

卡住時：不要自己嘗試別的做法，把畫面拍給維護人。

---

## A. Claude 桌面 App（Code 分頁）

### A0 打開 PowerShell 視窗

1. 用檔案總管打開這個包裹資料夾（裡面看得到 `VERSION`、`外掛`、`規則` 這些）。
2. 在資料夾空白處按住 **Shift** 再按滑鼠右鍵，選「在這裡開啟 PowerShell 視窗」。（沒有這個選項：點網址列，輸入 `powershell` 按 Enter。）
3. 下面每一段都是「複製 → 在 PowerShell 視窗按滑鼠右鍵貼上 → 按 Enter」。**整個過程用同一個視窗，不要關掉**。

> 提醒：裝好之後，這個包裹資料夾要一直留在原地，不能搬動、改名或刪除。

### A1 記住包裹位置、找到 Claude Code 程式

```powershell
$root = (Get-Location).Path
$c = (Get-Command claude -CommandType Application -ErrorAction SilentlyContinue | Select-Object -First 1).Source
if (-not $c) { $c = (Get-ChildItem -LiteralPath "$env:APPDATA\Claude\claude-code" -Directory -ErrorAction SilentlyContinue | Get-ChildItem -Directory | ForEach-Object { Get-Item -LiteralPath (Join-Path $_.FullName 'claude.exe') -ErrorAction SilentlyContinue } | Sort-Object { try { [version]$_.Directory.Parent.Name } catch { [version]'0.0' } } -Descending | Select-Object -First 1).FullName }
$root; $c
```

**看到什麼代表成功**：兩行路徑。第一行是這個包裹資料夾，第二行結尾是 `claude.exe`。第二行是空的 → 停下來找維護人。

### A2 看看已經裝了什麼

```powershell
& $c plugin list
$cfg = if ($env:CLAUDE_CONFIG_DIR) { $env:CLAUDE_CONFIG_DIR } else { Join-Path $env:USERPROFILE '.claude' }
$pj = Get-Content -LiteralPath (Join-Path $root '離線副本\mattpocock-skills\.claude-plugin\plugin.json') -Raw -Encoding UTF8 | ConvertFrom-Json
$loose = @($pj.skills | ForEach-Object { Split-Path $_ -Leaf } | Where-Object { Test-Path -LiteralPath (Join-Path $cfg "skills\$_") })
if ($loose.Count -gt 0) { 'MATT-LOOSE 已經有同名的 skill：' + ($loose -join '、') } else { 'MATT-LOOSE 沒有' }
```

**看到什麼代表成功**：一份清單（或 `No plugins installed`），最後一行是 `MATT-LOOSE 沒有`。
- 清單裡**已經有** `mattpocock-skills@…` → 跳過 A3。
- 最後一行是 `MATT-LOOSE 已經有同名的 skill：…` → 你以前用別的方式裝過 Matt 的工具，**跳過 A3**（不然每個工具會出現兩次），其他步驟照做。

### A3 Matt Pocock 的工具（官方方式，要等一兩分鐘）

```powershell
& $c plugin marketplace add anthropics/claude-plugins-official
& $c plugin install mattpocock-skills@claude-plugins-official
```

**看到什麼代表成功**：`Successfully installed plugin: mattpocock-skills@claude-plugins-official`。→ 跳到 A4。

**看到 `Failed`**（連不上 GitHub）：不要設定任何金鑰或登入，改貼下面這段（離線副本）：

```powershell
& $c plugin marketplace add (Join-Path $root '離線副本')
& $c plugin install mattpocock-skills@mattpocock-offline
```

**看到什麼代表成功**：`Successfully installed plugin: mattpocock-skills@mattpocock-offline`。

### A4 本包裹的主外掛

```powershell
& $c plugin marketplace add (Join-Path $root '外掛')
& $c plugin install dev-bingfa@dev-bingfa
```

**看到什麼代表成功**：`Successfully installed plugin: dev-bingfa@dev-bingfa`（或 `already installed`）。

### A5 存檔自動檢查（有 Python 才裝）

先檢查有沒有 Python：

```powershell
$py = $null
foreach ($cand in 'py -3', 'python', 'python3') {
  $p = $cand -split ' '; $exe = $p[0]; $rest = @($p | Select-Object -Skip 1)
  if (Get-Command $exe -CommandType Application -ErrorAction SilentlyContinue) {
    & $exe @rest -c 'import sys; sys.exit(0 if sys.version_info >= (3, 8) else 1)' 2>$null | Out-Null
    if ($LASTEXITCODE -eq 0) { $py = $cand; break }
  }
}
if ($py) { 'PYTHON-OK（' + $py + '）' } else { 'PYTHON 沒有可用的 Python 3.8 以上' }
```

（這段和 AI 版第 2 步的判斷完全一樣。）

- 看到 `PYTHON-OK` → 再貼：

  ```powershell
  & $c plugin install dev-bingfa-check@dev-bingfa
  ```

  **看到什麼代表成功**：`Successfully installed plugin: dev-bingfa-check@dev-bingfa`。

- 看到 `PYTHON 沒有…` → 不要裝。**自動檢查這項沒啟用**。替代做法：每次交付前對 AI 說「交付前請檢查：這次改過的 Python 檔裡，有沒有 `except Exception:` 或 `except:` 後面只有 `pass` 的地方？每一處請說明上游怎麼知道失敗、我在哪裡看得到。」

### A6 把規則加到 `CLAUDE.md`

1. 用記事本打開這個包裹裡的 `安裝指示-ClaudeCode.md`，找到「第 6 步」底下那一大段指令。
2. **從第二行**（`$dir = if ($env:CLAUDE_CONFIG_DIR) …` 那行）開始，一路選到那段的最後一行，複製。第一行 `$root = '<ROOT>'` **不要**複製（A1 已經設好了）。
3. 貼到 PowerShell 視窗，按 Enter。

**看到什麼代表成功**：`OK 規則已附加在檔尾：…`（或 `OK 規則已更新…`），下面有 `備份：…`。它會先備份你原本的 `CLAUDE.md`，只在檔尾加一段，重做也不會加第二次。

### A7 檢查

```powershell
& $c plugin list
```

**看到什麼代表成功**：有 `dev-bingfa@dev-bingfa`、一個 `mattpocock-skills@…`，有 Python 時還有 `dev-bingfa-check@dev-bingfa`，都是 `enabled`。

最後把 Claude 桌面 App **完全關閉**（右下角系統匣也要結束）再重開。開新對話打 `/`，應該看得到 `/dev-bingfa:commit`、`/mattpocock-skills:grill-me` 這類名字。

## B. ChatGPT 桌面 App 裡的 Codex（用檔案總管複製）

這條路不用打指令，只有最後加規則那一步要貼一段。

### B0 打開兩個資料夾

1. 視窗一：用檔案總管打開這個包裹資料夾。
2. 視窗二：在檔案總管的網址列貼上 `%USERPROFILE%` 按 Enter（會打開你的使用者資料夾，例如 `C:\Users\你的帳號`）。看不到以點開頭的資料夾也沒關係，下面會用網址列直接進去。

### B1 複製 4 個 skill

1. 視窗二的網址列貼上 `%USERPROFILE%\.agents\skills` 按 Enter。說找不到：先在 `%USERPROFILE%` 新增資料夾 `.agents`，再在裡面新增 `skills`。
2. 視窗一進到 `外掛\dev-bingfa\skills`，選取裡面的 4 個資料夾：`blast-radius`、`brownfield-recon`、`commit`、`seam-audit`，複製，貼到視窗二。

**看到什麼代表成功**：視窗二出現這 4 個資料夾。如果跳出「目的地已經有同名的檔案」：按**略過／取消**，不要取代，然後找維護人。

### B2 複製 3 個助手設定和搜尋策略

1. 視窗二的網址列貼上 `%USERPROFILE%\.codex` 按 Enter。（有設定 `CODEX_HOME` 的人改去那個資料夾。）裡面沒有 `agents` 資料夾就新增一個，然後進去。
2. 視窗一進到 `codex\agents`，複製 3 個 `.toml` 檔，貼到視窗二的 `agents`。
3. 在視窗二的 `agents` 裡新增資料夾 `bingfa-web-search-modules`，進去。
4. 視窗一進到 `外掛\dev-bingfa\web-search-modules`，複製裡面 5 個 `.md` 檔，貼進視窗二。

**看到什麼代表成功**：`agents` 裡有 `bingfa-explorer.toml`、`bingfa-implementer.toml`、`bingfa-web-search-agent.toml` 和 `bingfa-web-search-modules` 資料夾（裡面 5 個檔）。同名衝突一樣按略過、找維護人。

### B3 Matt Pocock 的工具

如果你以前已經在 Codex 裝過 Matt Pocock 的外掛，或 `%USERPROFILE%\.agents\skills` 裡已經有 `grill-me`、`tdd` 這類資料夾（不確定就問維護人），**跳過這步**，不然每個工具會出現兩次。

1. 視窗一進到 `離線副本\mattpocock-skills\skills\engineering`，選取裡面**所有資料夾**（20 個），**不要**選到 `README.md` 這個檔案，複製，貼到視窗二的 `%USERPROFILE%\.agents\skills`。
2. 視窗一進到 `離線副本\mattpocock-skills\skills\productivity`，選取裡面**所有資料夾**（7 個），一樣**不要**選 `README.md`，複製，貼到同一個地方。
3. `skills` 底下的 `misc`、`in-progress`、`deprecated` 三個資料夾**不要**複製。
4. 貼上時如果跳出「目的地已經有同名的檔案」：按**略過／取消**，不要取代——代表你以前用別的方式裝過 Matt 的工具，找維護人。

**看到什麼代表成功**：`%USERPROFILE%\.agents\skills` 裡多了 27 個資料夾，例如 `grill-me`、`tdd`、`code-review`。

### B4 把規則加到 `AGENTS.md`

1. 在視窗一的資料夾空白處按住 **Shift** 按右鍵，選「在這裡開啟 PowerShell 視窗」，貼上這行按 Enter：

   ```powershell
   $root = (Get-Location).Path
   ```

2. 用記事本打開 `安裝指示-Codex.md`，找到「第 3 步」底下那一大段指令，**從第二行**（`$dir = if ($env:CODEX_HOME) …`）開始選到最後一行，複製，貼到 PowerShell 視窗按 Enter。

**看到什麼代表成功**：`OK 規則已附加在檔尾：…`（或 `OK 規則已更新…`），下面有 `備份：…`。出現 `STOP` → 找維護人。

### B5 存檔自動檢查

這條路線**不裝**：**自動檢查這項沒啟用**。替代做法：每次交付前對 AI 說「交付前請檢查：這次改過的 Python 檔裡，有沒有 `except Exception:` 或 `except:` 後面只有 `pass` 的地方？每一處請說明上游怎麼知道失敗、我在哪裡看得到。」

最後把 ChatGPT 桌面 App **完全關閉**再重開。在 Codex 開新對話打 `$`，應該看得到 `commit`、`brownfield-recon`、`grill-me` 這類名字。
